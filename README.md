# ❤️ Heart Attack Risk Prediction API

A production-ready FastAPI system that evaluates heart attack risk and delivers
personalised healthy-habit recommendations using an ensemble ML pipeline.

## Prerequisites

Before deploying, ensure you have:

- Python 3.10+ installed
- Git installed
- Virtual environment tool (`venv`) or Conda (optional but recommended)
- Streamlit installed (`pip install streamlit`)

## 🏗️ Architecture

```
heart_attack_api/
├── main.py                    # FastAPI app entry-point
├── schemas.py                 # Pydantic request/response models
├── train_models.py            # Re-train ML models
├── requirements.txt
├── data/
│   └── heart_attack_prediction_dataset.csv   # 8,763 patient records
├── models/                    # Saved model artefacts (generated by train_models.py)
│   ├── rf_model.pkl           # Random Forest (200 trees)
│   ├── gb_model.pkl           # Gradient Boosting (300 trees)
│   ├── scaler.pkl             # StandardScaler
│   ├── le_sex.pkl             # LabelEncoder – Sex
│   └── le_diet.pkl            # LabelEncoder – Diet
├── routers/
│   ├── predict.py             # POST /predict
│   ├── recommendations.py     # POST /recommendations
│   └── stats.py               # GET  /stats
└── utils/
    └── model_loader.py        # Cached model loader
```

## 🤖 ML Pipeline

### Dataset
- **8,763** patient records, **26** features (demographics, vitals, lifestyle, medical history)
- Target: `Heart Attack Risk` (binary: 0=no risk, 1=at risk)
- Class split: ~64% no-risk / ~36% at-risk

### Models
| Model | Hyperparameters |
|---|---|
| Random Forest | 200 trees, max_depth=12, class_weight=balanced |
| Gradient Boosting | 300 trees, lr=0.05, max_depth=5 |
| Ensemble | Soft voting: 55% RF + 45% GB |

### Key Features (by importance)
1. Exercise Hours Per Week
2. Sedentary Hours Per Day
3. Income (socioeconomic proxy)
4. BMI
5. Triglycerides
6. Systolic Blood Pressure

## 🔌 Integrating HuggingFace Transformers

To replace the rule-based recommendation engine with a transformer model:

```python
# In routers/recommendations.py, replace generate_recommendations() with:
from transformers import pipeline

nlp = pipeline(
    "text-generation",
    model="microsoft/BioGPT-Large",   # or any health-focused LLM
    device=-1  # CPU; use 0 for GPU
)

def generate_recommendations(patient: PatientInput, risk_level: str) -> str:
    prompt = f"""
Patient profile: age={patient.age}, BMI={patient.bmi}, smoking={patient.smoking},
cholesterol={patient.cholesterol}, risk_level={risk_level}.
Provide 5 personalised heart health recommendations:
"""
    result = nlp(prompt, max_new_tokens=300, do_sample=True, temperature=0.7)
    return result[0]["generated_text"]
```

Recommended models:
- `microsoft/BioGPT-Large` – biomedical text generation
- `epfl-llm/meditron-7b` – medical LLM
- `sentence-transformers/all-MiniLM-L6-v2` – for semantic similarity matching
